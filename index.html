01 / PROJECT OVERVIEW

About This Project

The objective of this project is to explore Netflix's catalogue using SQL and answer analytical questions about movies and television shows.

🎯

Objective

Analyze Netflix content and explore patterns in content types, release years, ratings, runtime, countries and genres.

🛠️

Tools Used

SQL, MySQL concepts, aggregate functions, common table expressions, string functions and window functions.

📊

Dataset

Netflix titles dataset containing 8,807 records and 12 columns with movie and TV show information.

03 / DATASET STRUCTURE

Dataset Information

The dataset contains 12 columns describing Netflix movies and television shows.

show_id — Unique ID
type — Movie / TV Show
title — Title Name
director — Director
cast — Cast Members
country — Country
date_added — Date Added
release_year — Release Year
rating — Content Rating
duration — Runtime / Seasons
listed_in — Genres
description — Description
