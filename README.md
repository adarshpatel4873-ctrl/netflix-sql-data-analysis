# Netflix Data Analysis using SQL

## Project Overview
This project explores the Netflix Movies and TV Shows dataset using SQL. The goal is to analyze Netflix's content library and identify insights about movies, TV shows, genres, countries, and release trends.

## Live Project Website
[View Project Website](https://adarshpatel4873-ctrl.github.io/netflix-sql-data-analysis/)

## Dataset
- **Source:** Netflix Movies and TV Shows dataset
- **Records:** 8,807
- **Columns:** 12
- **Content types:** Movies and TV Shows

## Tools & Technologies
- MySQL
- SQL
- MySQL Workbench
- GitHub

## Project Files
- `netflix.csv` – Dataset
- `netflix_analysis.sql` – SQL analysis queries
- `index.html` – Project webpage

## Analysis Areas
- Movies vs. TV Shows
- Content ratings
- Release-year trends
- Country-wise content distribution
- Genre analysis
- Director and cast analysis

## Skills Demonstrated
- Data exploration
- SQL querying
- Filtering and aggregation
- Grouping and sorting
- Data analysis

## How to Use
1. Download the dataset and SQL file.
2. Import the CSV data into MySQL.
3. Execute the SQL queries in MySQL Workbench.
4. Explore the results.
